### 👨‍💻 About Us

**CreAPP** is a specialized software engineering studio and lab founded and directed by **Sebastián Maza**. We focus on building mission-critical web applications, high-performance SaaS platforms, real-time IoT telemetry pipelines, and customized business software.

* 🌐 **Specialization:** Full-cycle product development from architectural design to cloud deployment.
* 🛠️ **Engineering Principles:** Clean code, modular TypeScript architectures, real-time reactive state, and seamless UX/UI.
* 🚀 **Status:** Actively delivering production solutions for logistics, healthcare, sports management, and industrial IoT monitoring.

---

### 🛠️ Core Technology Stack

```
Frontend:     TypeScript • React.js • Next.js (App Router) • TailwindCSS • Modern HTML5/CSS3
Backend:      Node.js • Express • RESTful APIs • WebSockets • Serverless Functions
Data & Cloud: PostgreSQL • Firebase / Cloud Firestore • Supabase • Vercel • REST APIs
Domains:      Industrial IoT Telemetry • Multi-tenant SaaS • Custom CRMs • AI Integrations
```
